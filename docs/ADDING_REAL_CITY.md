# Adding a real city checklist

1. Choose city ID and display name.
2. Define a playable boundary.
3. Gather OSM, population, workplace, building, water, and POI sources.
4. Create the import config and manual overrides.
5. Run the city generator.
6. Validate generated level data.
7. Inspect the map.
8. Verify population and workplace counts.
9. Verify roads, highway stop rules, and water.
10. Add a manifest entry only for a valid generated module.
11. Run `npm test` and `npm run build`.
12. Record attribution and known limitations.
